# 🏪 Thogakade Management System (JavaFX)

A complete Thogakade (Store) Management System built using JavaFX, Java, and MySQL.
This application provides full CRUD operations for all major store components including Customer, Employee, Item, and Supplier.
Easy to use, fully customizable, and ideal for learning or real business usage. 💼✨

---

## 🚀 Features

### 👤 Customer Management
- ➕ Add new customers
- ✏️ Update customer details
- ❌ Delete customers
- 🔍 Search customers

### 🧑‍💼 Employee Management

- ➕ Add employees
- ✏️ Update employee information
- ❌ Remove employees
- 🔍 Search employees

### 📦 Item Management

- ➕ Add new items to stock
- ✏️ Update item details
- ❌ Delete items
- 🔍 Search items
- 📊 Manage stock availability

### 🚚 Supplier Management

- ➕ Register suppliers
- ✏️ Update supplier data
- ❌ Delete suppliers
- 🔍 Search suppliers

---

## 🛠️ Tech Stack

- ☕ Java (JDK 17 or later)
- 🎨 JavaFX
- 🗄️ MySQL
- 🔌 JDBC / SQL
- 🧰 Maven / IntelliJ IDEA / SceneBuilder (optional tools)
